## 📖 Overview

**Floribelle Knots** is an artisanal digital boutique designed with a **Tactile Minimalist** aesthetic. Built with pure HTML5, vanilla JavaScript, and Tailwind CSS, it offers a seamless zero-friction e-commerce experience without third-party payment gateway fees. All orders are dynamically compiled into itemized **WhatsApp order strings**.

---

## ✨ Key Features

- 🛍️ **Interactive Product Catalog**: 4 curated categories (Keychains & Charms, Gajras & Corsages, Laptop Sleeves, Gift Bundles) with instant search & tag filters.
- 🎨 **4-Step Customization Lab**: Real-time interactive configurator supporting 8 yarn color swatches, 4 clasp hardware options, custom monogram stamps, and handwritten gift notes.
- 🛒 **Slide-Over Shopping Bag Drawer**: LocalStorage-persisted cart with live subtotal, promo code engine (`CRAFT10`, `KNOTS200`), dynamic delivery fee calculators, and multi-item WhatsApp checkout generation.
- 🔍 **In-Modal Quick View**: High-resolution product showcase modal with materials breakdown (*100% Organic Milk Cotton*) and craft timelines.
- 💖 **Interactive Wishlist Drawer**: Save favorite items with one-tap heart burst animations and "Move All to Bag" bulk actions.
- 📱 **Mobile-First & Accessible**: Fully responsive layout with `Escape` key modal controls and smooth micro-interactions.

## ⚙️ Quick Start

No build tools or server dependencies required!

```bash
# Clone the repository
git clone https://github.com/Saba1512006/floribelle-knots-boutique.git

# Navigate to the project directory
cd floribelle-knots-boutique

# Open directly in browser or start a local preview server
python -m http.server 8000
```

## 🌐 Deployment & Hosting

### Option A: Netlify Drop (Instant Drag & Drop)
1. Visit [app.netlify.com/drop](https://app.netlify.com/drop).
2. Drag and drop the repository folder directly into the browser.

### Option B: GitHub Pages
1. Go to **Repository Settings > Pages**.
2. Under **Build and deployment**, select `main` branch and `/ (root)`.
3. Save to publish instantly.
